# Next Steps

1. Verify the auth flow cleanly in the browser after the backend route fix.
2. Set up Jenkins locally and run the `Jenkinsfile`.
3. Configure AWS CLI locally.
4. Apply Terraform bootstrap for `S3` and `DynamoDB`.
5. Apply Terraform dev foundation for `ECR`.

## After That

1. Install `kind` and run Kubernetes locally.
2. Apply the manifests in `k8s/base`.
3. Set up AWS CLI credentials.
4. Apply Terraform bootstrap only.
5. Create ECR repositories.

## Do Not Do Yet

1. Do not create EKS immediately.
2. Do not create NAT Gateway unless required.
3. Do not leave EC2 test instances running.
